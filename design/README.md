# Skill Manager 界面设计

基于当前 Go / mygo 项目的功能设计，交付可编辑的 Pen 图层与静态预览。没有修改业务代码，也没有操作本机 skill 数据。

## 文件

- `skill-manager.pen`：旧版 8 张画板。最新版 11 张画板在 Pen 里打开的 `untitled.pen`，尚未同步到这个文件。
- `skill-manager.pdf`：11 页浏览版（与最新画板一致）。
- `previews/*.png`：每张画板的 2× PNG。

## 页面

| 画板 | 工作任务 |
| --- | --- |
| 01 问题（无待处理） | 默认首页。没有问题时显示核对摘要和重新扫描；有问题时是 03 |
| 02 共享池 | 浏览 skill，查看来源路径、Agent 软链及只读正文 |
| 03 问题 | 按类别筛选，核对软链目标，批量或单项修复 |
| 04 依赖图 | 查看同一目录内的依赖和缺失节点 |
| 05 Claude | 按需比较实体副本，调整 Claude 用户级调用方式 |
| 06 关键交互与状态 | 比较结果、修改确认、撤销、只读、引用保护、缓存与搜索空态 |
| 07 生效视图 | 指定 Agent 与工作目录后，看哪些 skill 真正会被加载，以及同名副本为什么被覆盖 |
| 08 全貌 | 一个 Agent 在四个位置上能看到的全部 skill，按优先级排列成覆盖矩阵 |
| 09 仓库 | 查看仓库里的 skill，挂到共享池 |
| 10 Codex | Agent 页；没有 Claude 专属的调用方式设置 |
| 11 确认改为软链 | 在窗口内用 sheet 确认，默认按钮「改为软链」 |

## 视觉方向：macOS 桌面应用

这一版按 macOS 原生桌面应用重画，去掉网页式的大卡片、粗标题和彩色徽标。

- **窗口**：统一标题栏 + 工具栏，52 高，白底，下边一条 1px 分隔线。左边是 12pt 交通灯，右边是搜索框、视图切换和刷新。没有大标题、没有面包屑、没有渐变。
- **侧栏**：macOS 来源列表（source list）。分组标题用 11pt 灰色小字，行高 26，圆角 5，选中用系统蓝浅底加粗字，计数右对齐。底部一条分隔线放「添加仓库…」。
- **内容区**：白底。列表行高 32～44，靠分隔线和留白分组，不靠阴影和卡片描边。表格只有一条表头分隔线。
- **控件**：按钮 24 高、圆角 6，分主（系统蓝实心）、次（白底细边）、无边框（蓝字）三种。分段控件用系统灰底 + 白色滑块，不再用带图标的大 tab。
- **状态色**：只用三种，绿 `#2B7650` 正常、橙 `#996019` 警告、红 `#BD4045` 错误，都以文字形式出现，不做彩色胶囊。
- **菜单栏**：每张桌面画板顶部画了 macOS 菜单栏，标明这是桌面应用，命令走 App / 文件 / 编辑 / 显示 / 窗口 / 帮助。

| 强调 | `#007AFF`（系统蓝，用于图标、圆点、实心按钮底） |
| 强调文字 | `#0A5FD1`（蓝字，白底 5.88、浅蓝底 5.11，满足正文对比） |
| 选中底色 | `#E6F0FE` |
| 正常 / 警告 / 错误 | `#2B7650` / `#996019` / `#BD4045` |

系统蓝 `#007AFF` 配白字只有 4.02:1，低于正文要求，所以实心按钮的白字、蓝色文字链接统一改用 `#0A5FD1`；`#007AFF` 只用于图形（图标、状态圆点、选中底）。深色模式本次没有出图。

字号只有 11 / 12 / 13 三档正文，标题 17（详情）和 17（详情与空状态标题），没有 25 以上的展示字。中文 Noto Sans SC，英文 Inter，路径 Geist Mono —— Pen 不支持 `SF Pro` / `PingFang SC` / `Helvetica Neue`，落地到 mygo 时改用系统字体 `-apple-system` / `PingFang SC` / `SF Mono`。

## 数据与功能边界

所有数字、关系、摘要、正文和 hash 都是示例，不代表用户机器上的扫描结果。不同画板展示不同操作状态，不是同一次扫描的连续截图。`local-check` 是用于展示缺失节点的虚构依赖。

- 目录内容来源是磁盘。扫描只读取有限的头部元数据，不自动比较全部副本。
- 「副本待比较」不等于「不一致」。比较后才提供改为软链操作，比较结果不伪装成全局扫描统计。
- 搜索仅筛选当前列表；图不随搜索过滤。
- 问题页批量修复按类别计算，不随搜索词缩小。
- 共享池挂到 Agent 与仓库挂到共享池是独立操作，只创建软链。
- 移除目录、移除软链、不再扫描仓库是不同动作；不要混成「删除」。
- 已有 Agent 软链引用的共享池 skill 不应开放移除。示例中显示禁用动作和具体原因。
- 自带 skill 只读。Claude 调用设置只作用于 Claude 用户配置，不改 SKILL.md。
- 依赖图限当前目录，正文引用含推断。未新增全局关系图、在线安装、编辑器或试运行。
- 修复、替换和调用设置变更先确认；成功后 toast 提供撤销。未新增撤销历史页。

## 落地说明

这是静态设计稿，不是可点击原型，也不是已经实现的新 UI。窗口控件、按钮、文字和关系线都是可编辑图层。

主界面按 1180 × 760 绘制，外层桌面画板 1320 × 900，侧栏 224，列表 320。当前项目的最小窗口 880 × 560、深色模式、键盘焦点与 VoiceOver 需要在实现时单独验证，本次没有验证这些运行时能力。

建议实现顺序：来源侧栏与工具栏 → 列表和详情 → 修复及比较状态 → Claude 配置 → 依赖图 → 生效视图与覆盖矩阵。以当前业务行为为准，不让静态设计示例扩大实际功能。

状态动画建议只用约 120ms 的选中/淡入过渡；原生减少动态效果开启时关闭。图层不包含真实动画。

## 验证

用 Pen 的 `ctx.problems` 对 11 张画板逐个做越界检查，结果为 0 条裁切；再逐张导出 2× PNG 目视核对排版、中文换行、按钮标签、连线与选中态。PNG 为 2×（2640 × 1800）。没有在 mygo 里跑真实窗口，也没有做深色模式、键盘与 VoiceOver 验证。

## macOS 材质

侧栏是半透明浅色填充加 `background_blur`，桌面颜色在模糊后透出；内容区和工具栏保持不透明。开启「减少透明度」时应改为实心侧栏。

`assets/macos-wallpaper.jpg` 来自本机 macOS Sonoma 系统壁纸，只作演示背景，不是应用自有资产，也不要求打包分发。

材质与菜单栏是设计示意，没有修改 mygo 实现或原生窗口配置。

## 07、08：Agent 的 skill 视野

这两张画板回答同一个问题：**一个 Agent 在某次会话里，实际能看到哪些 skill**。它们是给「项目级 skill 覆盖全局 skill」做的界面方案，不是已实现功能的截图。

- 07 生效视图：先定 Agent（Claude Code）和当前工作目录（`~/codes/myself/skill-manager`），左边列出真正会加载的 skill，右边解释某一条为什么是这个版本。
- 08 全貌：不选具体目录，把一个 Agent 在四个位置上的全部 skill 排成矩阵，一眼看出谁生效、谁被覆盖、谁根本没装。

### 优先级假设

画板里用的顺序是 **项目 → 全局 → 共享池 → 内置**，同名只取最靠前的一层，其余版本留在磁盘但不加载。这是设计上的假设，用来把界面画清楚；真实实现里各 Agent 的加载顺序要按它自己的文档逐个核对，不能直接照抄。当前代码（`internal/skill/roots.go`）只扫描 home 下的固定目录，还没有项目级扫描，也没有同名覆盖判定，所以这两张图不能当成现有行为的截图。

### 界面约定

- 生效列表每行一个来源（项目 / 全局 / 共享池），第二行是磁盘路径，不写说明文字。
- 「为什么是这一个」用 1 / 2 / 3 三行表示查找顺序，生效那行浅蓝底加圆点，被覆盖的行写「被覆盖」，不写「不一致」——这里讲加载顺序，不是内容差异。
- 被覆盖的副本单独一段，只给「比较差异」和「改为软链」，不提供删除；删除仍走问题页。
- 08 的矩阵单元格只用三种状态：生效（蓝点）、被覆盖（灰点）、不存在（`—`）。行末给「生效来源」，一个都没有的标「未安装」。
- 切换工作目录会重算 07 的整页内容；底部给了两个示例目录，说明同一台机器上答案确实会变。

### 仍是示例的部分

目录名、数量（12 / 104 / 128 / 8）、`local-check`、`security-review`、`writing`、以及「比项目版本旧 2 天」这类描述都是编的，只用来演示状态。真实实现需要磁盘扫描结果和按需比较，不要把推断写成统计。

## 本轮修改（macOS 风格与信息架构）

- 侧栏改为真正的磨砂：窗口底色透明，只有内容区和工具栏不透明；开启「减少透明度」时改实心。
- 选中态：侧栏用浅灰圆角底、字不加粗；中间列表用内缩 8 的圆角强调色实底、白字（`#0A5FD1`，白字 5.88:1）。
- 去掉「总览」。侧栏顺序：浏览（问题、共享池）、AGENT（生效视图、各 Agent）、自带只读、仓库。「全貌」只作为 07 里的视图切换。
- 07、08 工具栏加了 Agent 选择器；07 的「换个目录」示例收成一行说明。
- 详情页顶部操作统一：主操作加「⋯」更多按钮，其余收进菜单（菜单本身未画）。
- 每个窗口只有一个默认按钮；确认改为 sheet（见 11），成功后撤销用 `⌘Z`，不再画深色 toast。
- 依赖图连线加深并带箭头；颜色只表示状态，来源与副本数用灰字。
- 新增画板：09 仓库（team-skills）、10 Codex（没有 Claude 专属的调用方式）、11 确认改为软链 sheet。
- 计数单位统一为「项」。
